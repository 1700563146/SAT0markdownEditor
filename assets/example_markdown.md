## 表格

| 功能 | 语法 | 说明 |
| --- | --- | --- |
| 加粗 | `**文本**` | 显示为粗体 |
| 斜体 | `*文本*` | 显示为斜体 |
| 删除线 | `~~文本~~` | 显示删除线 |

## 脚注

Markdown 支持脚注[^1]，可在文末添加注释内容。

行内脚注也可以直接书写[^注]。

[^1]: 这是脚注一的内容说明。
[^注]: 这是行内脚注对应的注释内容。

## 转义与特殊字符

展示原样字符时需要转义：\*星号\*、\_下划线\_、\#井号\#、\>大于号\>。

普通字符无需转义：100% 完成、A & B、@someone。
