## [1.6.4] - 2026-10-11

### 性能

- **编辑器 web 资源包从 4.66MB 压到 2.84MB（-39%）**：用精选的 14 种 CodeMirror 语言表
  替换全量注册表（去掉 `@codemirror/legacy-modes` 与 20 多个 `lang-*` / `@lezer` 语法包），
  KaTeX 字体只保留 woff2（去掉 woff/ttf 回退，约 1.1MB），并把产物从「单文件 HTML」拆成
  `index.html` + 独立 JS/CSS/字体 —— 内联脚本无法命中 V8 代码缓存，拆分后才行。
- **新增 `MilkdownAssetServer` 取代插件自带的 `InAppLocalhostServer`**：入口资源常驻内存、
  响应带 `immutable` 缓存头，配合按应用版本编址的 URL，让 WebView 的 HTTP 缓存与 V8 代码缓存
  跨「打开文档」复用；不再每次打开都清空整个 WebView 缓存并重新读取 4.66MB 资源。
- **冷启动即预热编辑器**：首页绘制完成后挂一个 1x1 离屏 WebView，加载同一 URL 并用空文档
  建一次编辑器，把引擎初始化、缓存落盘、首次建实例的成本从「打开文档」挪到「打开软件」。
  真正开始打开文档时自动让位，避免低端机上同时存在两个 WebView 实例。
- **预览/编辑来回切换不再重启编辑器**：此前切换模式会把预览面板（Android 平台视图）整个卸载
  再重建，等于每次切换都要重新加载并求值整个编辑器（实测热态 ~440ms、冷态 ~1.4s）。
  改为两个面板常驻树内、只切换可见性，编辑态冻结下发内容。
- 就绪检测由 100ms 步长轮询改为 JS 主动回推；release 下移除逐资源、逐诊断的 Dart→JS 往返；
  bridge 载荷单次编码直注（大文档注入体积近乎减半）。

### 修复

- **修复打开/关闭文档的「卡顿感」**：这不是掉帧（帧率统计 95 分位 19ms、jank 0%），而是过渡
  期间整页没有内容 —— 液态玻璃下加载骨架屏底色透明，路由淡入时能透过编辑器看到上一页，
  内容再在几百毫秒后凭空出现。现改为实色占位底板、遮罩淡出而非硬切、去掉预加载时额外的
  转圈模态框；按返回时也不再立刻抽掉内容，改为退场动画播完后再销毁平台视图。

## [1.6.3] - 2026-10-10

### 修复

- **修复更新检查永远提示"有新版本"的问题**：应用版本号此前硬编码在 `AppConstants.appVersion`，
  发版时未同步更新，导致已是最新版仍被判定为需要更新（如 1.6.2 仍提示更新到 1.6.2）。
  现改为启动时通过 `package_info_plus` 读取 pubspec 的真实版本号，彻底消除版本漂移；
  关于页显示与更新检查均随之正确。

## [1.6.2] - 2026-10-10

### 修复（紧急热修复）

- **修复确认对话框在部分安卓设备（如 MIUI 14 / Android 13）上无法点击/无法关闭的问题**：
  1.6.1 将删除文件/文件夹、新建文件夹、清空历史、丢弃修改、回退版本等确认对话框改用
  `GlassDialog`，其按钮在个别设备上点击不生效，且默认不可点击外部关闭，导致模态遮罩卡死、
  整个界面无法操作（表现为“删除不了 / 新建不了 / 点了没反应 / 取消无效”）。
  现全部回退为标准 `AlertDialog`（按钮可靠、可点击外部关闭），彻底消除卡死。

  `onSurfaceVariant`、`outline`、`outlineVariant`、`secondaryContainer`，

  交给 `GlassIconButton` 处理，不再被外层显式色绕过。

  `GlassCard` 修复玻璃模式下双重 16px 内边距，Markdown 工具栏容器
  与历史页分段开关在玻璃模式下接入真实玻璃材质。
- 高频确认对话框改用 `GlassDialog`：清空历史、删除文件/文件夹、
  丢弃修改、回退版本、新建文件夹等 7 处玻璃模式下显示玻璃材质。
- 桌面端隐藏系统标题栏，消除双标题栏；桌面导航栏在玻璃模式下使用
  玻璃容器。
- 清理死代码：移除已替换的旧外观设置页、旧 Markdown 预览与
  `unified_ui.dart`（约 4450 行），删除遗留的静态 `lightTheme` /
  `darkTheme` 与未使用的 `flutter_highlight` 依赖。

### 修复

- 修复历史页玻璃模式下文件/文件夹分段切换标签拥挤的问题：
  分段控件改为固定 140px 宽度，两个中文标签恢复分隔。
- 移除 Android 预测性返回动画：页面过渡改为普通渐隐滑动，
  系统返回手势不再触发缩放预览。

### 修复

- 修复启动时存储权限弹窗时机：权限检查完成前不再渲染权限页，已授权
  状态下请求权限也不会再触发系统弹窗。
- 修复软键盘弹出时主界面整体被顶起的问题：主界面不再跟随键盘压缩，
  悬浮胶囊底栏与页面背景保持原位，键盘覆盖在内容上方。

### 优化

- 关于页新增“稳定版 / 测试版”更新规则切换：稳定版仍使用 GitHub latest，
  测试版优先扫描最新 pre-release，并随启动自动检查更新生效。
- 液态玻璃风格整体迁移到 `liquid_glass_widgets` 包，替换原来手写的
  `BackdropFilter` 模糊实现，获得真实折射、色散与高光效果：
  - 液态玻璃卡片与底部导航胶囊改用包提供的 `GlassContainer` / `GlassTabBar`。
  - 应用启动时预加载 shader，全局按主题亮度联动玻璃明暗。
  - 胶囊底栏保持仅图标显示，设置页导航样式预览同步切换为真实玻璃渲染。
  - 移除未接入的遗留 shader 文件与已废弃的液态玻璃效果开关设置项。
- UI 风格成为液态玻璃的唯一开关，选择“液态玻璃”后全局生效：
  - 卡片、各类按钮与底部导航同时切换为 `GlassContainer` 玻璃渲染，
    按钮通过主题级 `backgroundBuilder` 接入玻璃背景。
  - 其余两种 UI 风格保持原有外观，不受玻璃效果影响。
  - 设置页中独立的“底部导航栏样式”选择器已移除，底栏随 UI 风格切换，
    仅保留底栏透明度调节。
  - 玻璃模式下卡片与表面层不再叠加重复的装饰阴影和填充。
  - 首页快速工具卡片、文件夹浏览页头部图标按钮与排序按钮、
    编辑器右下角悬浮按钮统一接入玻璃渲染，玻璃模式下不再有白底/实色底。
    编辑器悬浮按钮为纯玻璃底配全局图标色，不叠加彩色样式。
  - 编辑器顶栏改为全悬浮布局：返回/保存/更多按钮与文档信息胶囊悬浮于
    内容之上，编辑器内容全屏延伸；文档信息区在玻璃模式下为玻璃长条胶囊，
    其他风格保持原有的浅色胶囊底。搜索栏打开时顶栏自动隐藏，避免遮挡。
  - 玻璃模式全面去色彩叠加：按钮、输入框、悬浮按钮与头部按钮不再垫
    主题色底或彩色图标，统一呈现库默认的透明玻璃质感，文字使用主题文字色。
  - 新用户默认 UI 风格改为“液态玻璃”；已有用户的本地设置保持不变。
  - 编辑器悬浮顶栏的返回按钮、信息胶囊、保存按钮与更多按钮统一为
    40px 等高对齐，文件名改为单行省略显示，避免信息区凸出。
- 重新设计预设主题配色，深浅色方案分别替换为 Catppuccin、Rosé Pine、
  Nord、Tokyo Night、Dracula、Gruvbox、Solarized 等开源配色：
  - 深色主题：摩卡夜色、松林暮色、极地冰蓝、东京夜蓝、德古拉之夜、复古炭灰。
  - 浅色主题：拿铁奶油、松林晨光、东京晨蓝、复古暖纸、日光暖黄。
  - 新增 WCAG AA 文字对比度测试，见 `test/utils/theme_scheme_test.dart`。

## [1.6.0] - 2026-08-26

### 新增

- 移动端底部导航栏新增“液态玻璃胶囊”样式切换：
  - 外观 → 其他设置 → 底部导航栏可选择“经典底栏”或“液态玻璃胶囊”。
  - 胶囊样式为浮空玻璃胶囊，选中项带滑动胶囊高亮动画，仅图标显示。
  - 支持按住胶囊滑块左右拖动切换 tab：按下有缩放反馈，松手吸附到最近的 tab。
  - 历史页右上角的文件/文件夹切换按钮同步支持按住拖动切换，带缩放反馈并吸附到最近选项。
  - 样式独立于 UI 风格，默认保持经典底栏，不影响现有用户。

### 修复

- Markdown 单回车现在按真实换行渲染，空行分隔的段落保留约一行高的可见空行，
  不再需要手动加两个空格才能换行。
- 打开 md 文件以及编辑/预览模式之间切换时按原文解析，不发生任何内容或格式变更：
  setext 标题按标准 Markdown 渲染，未真实编辑时不会标记“已修改”、不会触发自动保存或退出保存，源文件保持原样。
- 修复包含代码块、HTML、嵌套列表等复杂结构的文档在打开初始化阶段仍会上报一次
  `on_content_change` 的问题：初始化渲染期间的 Milkdown 内部事务不再被当作用户编辑，
  首次用户输入后才恢复内容变更上报。
- 修复文档下滑时被光标视口同步回跳到文档开头的问题：只有真实编辑交互（点击、输入、
  键盘操作）后才执行光标同步，程序化聚焦不再触发原生滚动。
- 统一历史页与设置页左上角标题/图标的位置：左侧边距、图标尺寸、图标与文字间距、
  标题字号一致，标题文字与图标垂直对齐。
- 统一“我的文件 / 历史 / 设置”页面第一个卡片顶部到软件顶部的距离：
  三个页面头部统一为相同高度，列表顶部间距保持一致。
- 液态玻璃胶囊底栏改为真正的悬浮覆盖层，不再占用底部导航栏槽位：
  四个主 tab 页面全屏延伸至手机底部边缘，滚动内容可滑到悬浮胶囊下方。
  底部滚动余量按胶囊实际测量高度动态计算，适配不同分辨率与系统导航栏高度。
- 修复历史页因文件/文件夹切换组件在无界宽度下布局异常而无法显示的问题，
  分段开关现在自带默认宽度，可正常渲染并支持拖动切换。
- 历史页文件/文件夹切换滑块改为完整包住整个分段，圆角与外部容器保持一致（12）。
- 修复液态玻璃胶囊底栏选中滑块未对准图标中心的问题，改为按槽位精确居中。
- 修复切换 tab 时选中滑块瞬移/消失重显的问题，改为显式动画控制器驱动的连续滑动过渡（260ms）。
- 修复预览页撤销/重做：撤销按钮的可用状态改为跟随 Milkdown 编辑器真实历史，
  没有可撤销/重做内容时按钮禁用，不再弹出“编辑命令失败: undo (not_applicable)”。
- 修复切换文档或模式后 Milkdown 初始化写入被计入撤销历史，导致首次撤销会清空文档的问题。
- 修复预览模式“目录”悬浮按钮遮挡“标题 1/标题 2”的问题，悬浮按钮列上移到底部工具栏上方。
- 搜索正文高亮改为 ProseMirror decoration 实现，匹配不再被编辑器重绘立即移除，支持 active 高亮。
- 搜索关闭/跳转后重新聚焦编辑器并释放 Flutter IME client；Android 真机键盘恢复仍需复核。
- 大文件（>512KB）支持渐进渲染与 15 秒首帧超时安全网，可继续等待或返回，不再永久卡在“正在加载内容...”。
- 非法 UTF-8/二进制文件读取抛出带路径的 `FileEncodingException`，编辑器/导航层给出明确错误提示，不再静默退回。
- 保存时按文档原始换行风格写回，CRLF 文件不再被转成 LF。
- 文件列表支持显示并打开无扩展名的文本/Markdown 文件；`stat` 异常时显示“未知”而非 `-1 B · 1970/1/1`。
- 非 ASCII 文件名统一使用 `FileSystemEntity.path` 构造路径，避免编码转换导致文件打不开。

### 测试

- 新增 `tab_bar_style` 设置持久化单元测试与液态玻璃胶囊底栏组件测试。
- 新增 `on_history_state` 桥接事件的分发与序列化单元测试。
- 新增 `FileService` 编码/CRLF/二进制检测单元测试。
- 新增模拟器预览/编辑 QA 报告：见 [QA_REPORT_2026_08_25.md](QA_REPORT_2026_08_25.md)，
  覆盖预览/编辑、搜索、目录、版本历史、自动保存、边界文件与压力操作。

  - 添加 null 检查防止重载时的空引用异常

- **main.js (JavaScript)**
  - 添加 bfcache 防护：检测 `pageshow.persisted` 并强制刷新
  - 添加缓存控制 meta 标签防止页面缓存
  - 添加 `forceRender` 选项到 `setMarkdown` 支持文档切换时强制渲染
  - 添加详细调试日志

### 技术细节

```
问题根因分析：
1. 编辑器关闭时，dispose() 关闭了共享的 _warmServer
2. 第二个编辑器尝试复用已关闭的服务器
3. WebView 加载失败，JavaScript bridge 未初始化
4. 浏览器 bfcache 恢复页面状态但不重新执行 JavaScript

解决方案：
1. dispose() 时检测是否为预热服务器，不关闭共享实例
2. 添加 JS bridge 就绪检测循环（最多 5 秒）
3. bridge 未就绪时自动重新加载页面
4. JavaScript 端检测 bfcache 恢复并强制刷新
```
